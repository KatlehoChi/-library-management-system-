# Library Management System (C#)

This is a simple **C# console application** that simulates a small library management system.  
It was created as part of my **Microsoft Full Stack Developer course on Coursera**, where I’m learning programming fundamentals and building hands-on projects.

##  Features
- Store up to five book titles.
- Add books if slots are available.
- Remove books by title.
- Display all non-empty book slots.
- Loop until the user chooses to exit.

##  Learning Context
As a student studying **Full Stack Development with Microsoft via Coursera**, this project helps me practice:
- String variables.
- Conditional statements.
- Loops.
- User input handling.
